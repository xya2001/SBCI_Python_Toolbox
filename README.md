# SBCI Toolbox has moved

This repository is archived and no longer updated. The SBCI Toolbox (the `sbci`
Python package) now lives at
**[sbci-brain/SBCI_Toolbox_Python](https://github.com/sbci-brain/SBCI_Toolbox_Python)**,
with the same history and every update since.

Install it from there:

```bash
pip install "sbci @ git+https://github.com/sbci-brain/SBCI_Toolbox_Python.git"
```

The commits here stay available, so an install pinned to one of them still works.
